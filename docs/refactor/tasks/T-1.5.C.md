# T-1.5.C — packwiz: переход с встроенного `http_request` на host-функцию `http_get`

| Поле | Значение |
| --- | --- |
| Статус | not_started |
| Шаг плана | Фаза 1.5 (заведена по F-16, в исходном плане отдельным шагом не описана) |
| Репозиторий | packwiz-plugin |
| Зависит от | T-0.6 |
| Модель | Claude Sonnet 5 — миграция в рамках готового контракта |
| Ревью перед мержем | нет |

## Что сделать
T-0.6 добавил host-функцию `http_get`, которая проверяет `allowed_hosts` в хосте, режет
приватные адреса и **не ходит по редиректам**. Встроенный `http_request` Extism оставлен как
fallback и редиректы по-прежнему следует, то есть N1 (обход `allowed_hosts` через 302) для
packwiz остаётся эксплуатируемым, пока плагин им пользуется (F-16).

Перевести обе точки вызова на `http_get`:
- `get_pack_from_path_or_url` — загрузка `pack.toml` по URL;
- `download_redistributable` — скачивание `packwiz-installer.jar`.

Объявить `http_get` в `extern "ExtismHost"` и обновить `aether-core-plugin-api` до версии
с `HttpRequestDto`/`HttpResponseDto`.

## Файлы
- `packwiz/src/features/packwiz/app/get_pack_from_path_or_url.rs`
- `packwiz/src/features/packwiz/infra/redistributable.rs`
- `packwiz/src/features/host/infra/host_functions.rs` (объявление `http_get`)
- `packwiz/Cargo.toml` — пин `aether-core-plugin-api` на тег с новыми DTO (Q5)

## Как проверить
- `xtask build` в репозитории плагина.
- Ручной сценарий: импорт packwiz-пака по URL и обновление пака — `pack.toml` и
  `packwiz-installer.jar` скачиваются через `http_get`.
- `grep` по `extism_pdk::http` / `HttpRequest` в `packwiz/src` — не должно остаться вызовов.

## Ловушки
- `http_get` отдаёт ошибку на любой 3xx. Если реальные URL (например, ссылки на релизы GitHub)
  отвечают редиректом, добавить конечный хост в `allowed_hosts` и ходить по нему напрямую;
  «тихо следовать редиректу» — не вариант, это ровно то, что закрывает T-0.6.
- Лимит тела ответа в хосте — 16 MiB. Для больших файлов нужна `download_to_cache` (T-1.2),
  а не `http_get`.
- После миграции плагин требует ядро с T-0.6 — поднять минимальную `apiVersion`.

## Проверка перед мержем (компенсация уровня модели)
Модель — Sonnet, поэтому обязательны:
1. Сборка плагина через `xtask` и установка в aether.
2. Ручной сценарий импорта и обновления пака целиком (см. «Как проверить»).
3. `grep` подтверждает, что вызовов встроенного `http_request` в плагине не осталось.
