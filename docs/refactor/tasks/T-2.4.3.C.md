## Что сделать
Лёгкий обработчик: скачать/прочитать только `pack.toml` и вернуть `PackMetadata`
(имя, версия, minecraft-версия, лоадер и его версия, описание). Без чтения индекса
и без резолва файлов — это и есть смысл шага (preview и check-updates).

## Файлы
- `packwiz/src/features/packwiz/app/*`
- `packwiz/src/lib.rs`, `packwiz/capabilities.json`

## Как проверить
- `cargo test -p packwiz` на фикстуре `pack.toml`.
- Ручной сценарий: в UI перед установкой пака показываются имя/версия/лоадер (после T-2.5).

## Ловушки
- Лоадер извлекается из секции `versions` (`fabric`/`forge`/`quilt`/`liteloader`) — уже есть
  `extract_mod_loader`, переиспользовать.
