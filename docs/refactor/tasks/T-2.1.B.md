## Что сделать
Типы, которых требует новый трейт: `ResolveInstallPlanParams` (content_id, версия, target,
game_version, loader, набор опциональных файлов), `PackSource` (URL / локальный файл /
идентификатор контента), `PackMetadata` (имя, версия, game_version, loader, счётчик файлов,
иконка), `ResolvedFile` (url, hash, имя, размер, относительный путь).
Плюс вариант ошибки `InstanceError::UnsupportedOperation { provider_id, operation }`.

## Файлы
- `features/instance/domain/model/install_plan.rs` (или соседний модуль)
- `features/instance/domain/model/error.rs`

## Как проверить
- `cargo check -p aether-core`, clippy без предупреждений.
- Модели покрывают оба сценария из плана: одиночный мод и модпак — зафиксировать это
  двумя юнит-тестами-конструкторами.

## Ловушки
- `ResolveInstallPlanParams` должен покрывать и `InstallTarget::New`, и `Existing` — иначе
  update пойдёт другим путём, чего план явно не хочет.
- Не тащить сюда DTO плагинного API — это T-2.4.4.
