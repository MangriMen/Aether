## Что сделать
- Удалить из плагина весь jar-путь: `redistributable.rs` (скачивание
  `packwiz-installer-bootstrap.jar`), `get_command_to_update_pack`, вызовы `run_command`,
  `get_java`/`install_java`, `preload_resources`.
- Перевести оставшиеся HTTP-запросы на host-функцию `http_get`.
- По решению Q1 — либо оставить `importers`/`updaters` обёртками над `resolve_install_plan`,
  либо удалить их и перенести сценарии импорта/обновления в ядро.
- Сузить `allowed_hosts` плагина до реально нужных.

## Как проверить
- Ручной сценарий 1: импорт пака в новый инстанс — Java не скачивается, jar не появляется.
- Ручной сценарий 2: обновление уже установленного пака — изменённые моды перекачиваются,
  удалённые исчезают, вручную добавленные остаются.
- Ручной сценарий 3: «обновление при запуске» (`update_on_launch`) ведёт себя как раньше.

## Ловушки

- `PackwizSettings { pack_path, update_on_launch }` хранится в инстансе — формат не ломать
  без миграции.
