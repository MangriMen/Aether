## Что сделать
Клиент `api.curseforge.com` (через host-функции `http_get`/`http_post_json` из Фазы 1,
а не через встроенный `http_request`) и три обработчика провайдера: поиск, получение проекта,
список версий файлов. Маппинг типов контента CF (classId) в `ContentType` ядра.

## Файлы
- `curseforge_plugin/src/features/curseforge_api/*`
- `curseforge_plugin/src/lib.rs` (экспорт функций плагина)
- `curseforge_plugin/capabilities.json`

## Как проверить
- Сборка плагина; ручной сценарий: поиск модов по CurseForge в UI возвращает результаты,
  карточка мода открывается, список версий заполнен.

## Ловушки
- `allowed_hosts` должен содержать и домен API, и домены отдачи файлов (`*.forgecdn.net`).
- Пагинация CF (`index`/`pageSize`) не совпадает с моделью ядра (`page`/`page_size`) —
  конвертировать аккуратно, иначе UI будет листать вхолостую.
