# Расхождения плана с текущим кодом

Зафиксировано при разборе `refactoring_plan.md` по исходникам `aether`, `packwiz-plugin`,
`curseforge-plugin` (2026-09-20). Новые расхождения дописывать сюда, а не в карточки задач.

Колонка «Статус» обновлена 2026-09-20 после решений владельца по всем 9 вопросам
(`OPEN_QUESTIONS.md`). «Закрыто» означает, что расхождение снято принятым решением;
«открыто» — что оно остаётся и учитывается в конкретной задаче.
